# 目前工作

現行版本 **v2.2.20**。本頁只維護工作狀態、未完成項目及停止邊界；驗收結果見 [TEST_REPORT](TEST_REPORT.md)，歷史證據由 [HISTORY](HISTORY.md) 追溯。

## 目前狀態

使用者批准的三批程式清理、自動驗證、安全差異審查、正式封裝、main／標籤推送及公開發布核對已完成，結果集中於 [TEST_REPORT](TEST_REPORT.md)。程式交付完成後，使用者另行要求核對已更新的 v2.2.20 安裝身分與變更接線。

一般頁面查證已確認 v2.2.20 可見版本、總覽／詳細狀態／CDN／播放設定頁，以及影音回應與量測／恢復狀態的介面接線；已完成清理。完整安裝本體、私有執行個體與內部協定接線仍未驗證，不以介面結果代替。結果、更正及原 INVALID 見 [一般頁面查證紀錄](TEST_REPORT.md#v2220-一般介面版本與狀態接線2026-11-13)。遵守 [AGENTS](../AGENTS.md#使用者永久執行禁令) 的 Tampermonkey 探索禁令及 Codex 已關閉 CDP 的工具限制；已通過的介面操作不重跑。低緩衝與提前重試效益研究保持暫緩。

使用者另要求窮盡新的授權取證路徑；當次公開工具、頁面能力與來源資料流調查已完成，逐條結果與原要求覆蓋表見[取證路徑調查](TEST_REPORT.md#v2220-授權取證路徑調查2026-11-13)。沒有找到可補足完整本體與私有協定時序的新入口；原安裝驗收仍未完成，未刪減測試或以 UI 摘要補算通過。後續重試須有具體新能力或證據來源，不能重複已拒絕的操作。

既有 v2.2.19 R1 已結案；其通過範圍、原 FAIL／INVALID 及未實測分支見[完整歷史](../archive/retired/docs/TEST_REPORT_HISTORY.md#v2219-完整正文保存2026-11-12)，不自動補跑。沒有新增已確認且待修復的功能缺陷。

## 暫緩項目

以下保持暫緩，不排成下一步優先順序。證據不足不等於功能失效，也不構成必須補驗的理由；只有可重現的使用者問題或具體程式缺陷需要處理時，才提出相應方案，瀏覽器新輪次另須明確授權。

| 項目 | 保留範圍與限制 |
| --- | --- |
| 大型恢復／播放器結構 | 維持現有狀態所有權，本次清理不進一步拆分 |
| 低緩衝 `stable-retained` | R2 已有真實元件解除抑制與額度保持證據；安裝版分支仍未驗證，不為消除證據缺口安排補驗 |
| 提前重試適用率、交接成本與效益 | 保留原離線效用 FAIL；觀察窗口、游標與請求分母校準隨效益研究一併暫緩。沒有完整配對不公布精確適用率，不把預測當作因果收益 |
| 正數 timeout 的提前重試資格 | 維持現行排除，不擴張；正數 timeout 起播測速的通過證據不能代替提前重試資格判定 |

提前重試既有觀察及效用限制見[自然研究](../archive/retired/docs/EARLY_RETRY_APPLICABILITY_RESEARCH_v2.2.12_2026-11-08.md#自然請求與逐層分母)，原結果不改寫。

## 歷史問題與條件式證據

這些項目依新前提才補，沒有排入目前執行工作。不能靠反覆刷新、重設預算或重跑正常播放來消除缺口。

| 項目 | 保留的缺口與啟動條件 |
| --- | --- |
| Native 來源更新 | v2.2.13 R5 受控真實 API→Vault changed-set 已有證據；同集合、晚到控制及自然 SDK 採用限制依[原報告](../archive/retired/docs/TEST_REPORT_HISTORY.md#v2213-完整正文保存2026-11-08)保留 |
| 真正跨分頁協作 | 多 Store 契約不等於 Tampermonkey 雙分頁實測；現行單一 IAB 限制保持，不能為補證據自行開第二分頁 |
| 健康中段與其他條件式通道 | 健康中段、家族排序、提前重試許可撤銷及 HTTPDNS 的證據層級依[原覆蓋表](../archive/retired/docs/TODO_OPTIMIZATION_RESEARCH_v2.2.11_2026-11-07.md#五條件式覆蓋與證據分層)；不另開窗口湊樣本 |
| P01／P02 | bounded prepare／等待者交錯的安裝證據仍缺；須明確恢復要求及指定影片自然 pending gate 的新前提 |
| CC39-R01／N05 卡頓 | 移除 Evolved 後未再現；舊取消請求發起者及根因未確認，不把一次正常窗口當作已解決 |
| CC39-R02／HK04 | 合法備援恢復資格缺陷已修復；舊 emptied／loadstart 原因仍未知，修後自然恢復缺口保留 |
| CC39-R03／香港供片 | 舊影片 timeout 與 INVALID 取證原判保留；修後影片 circuit-open、由其他 CDN 供片，音訊 206 不能代算該主機影片成功 |
| 工具鏈可重現性 | 乾淨安裝尚未新增驗證；其他平台與未來 Runtime 不由單次相容結果外推，也不恢復精確版本鎖定 |

舊案例的來源、實際主機與原始限制見 [TEST_REPORT 歷史導覽](TEST_REPORT.md)及 [HISTORY](HISTORY.md)。歷史根因未識別不等於現版仍存在可重現故障。

## 執行邊界

- v2.2.8 發行採離線交付，後續另獲授權的 R2 專項與原生校準亦已結案；v2.2.6、先前撤除及各版舊輪次維持原結案，自動結果與安裝實測分開。
- 瀏覽器只用 IAB＋Tampermonkey，同時一個自有測試分頁，保持靜音；其餘永久界線與已確認靜音方法見 [AGENTS](../AGENTS.md#使用者永久執行禁令)。
- 已通過項目不重測。新案例必須先凍結範圍、次數、硬截止、清理時間與可沿用證據；不繼承舊輪次剩餘預算或自動安排重跑。
- 原十二個五分鐘窗口、IR36、自然起因、BR-01 歷史矩陣及已撤銷 CDN 研究維持停止／結案，不隨工具恢復、文件整理或發布啟動。
- P01 bounded prepare／P02 真 gate 仍須使用者明確恢復要求及指定影片自然 pending gate 的新前提；不改網站 timeout、重設預算或反覆刷新製造條件。
- 過往輪次對控制中心入口／返回導覽的跳過決定保留；v2.2.6 R1 另獲授權的入口、三頁及重開結果依當輪紀錄，不將舊跳過限制套用為本輪未測，也不追加新的導覽測試。
- 不實作未授權的偏好記憶、提高探測頻率或其他平台擴展；舊採用否決與原 FAIL／INVALID 保留。
