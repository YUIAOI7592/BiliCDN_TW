# v2 工作狀態與後續方向

更新：2026-10-17。現行版本 **v2.1.27**，以 [release.json](../release.json) 為準；產品驗收結果見 [TEST_REPORT](TEST_REPORT.md)。

## 現在的執行狀態

目前批准的工作只有文件重整與維護工具：歷史原位、集中導覽、正式 docs:check、分階段驗證／提交及推送 main。產品版本與本體保持不變，不發布、不開安全掃描或瀏覽器窗口。

| 工作 | 狀態與範圍 |
| --- | --- |
| 文件清單與保護基準 | 已提交，重整前快照已保存 |
| 正式文件檢查 | 已提交並納入 verify；證據見工具紀錄 |
| 內容收斂與完整核對 | 進行中，完成後另記乾淨 checkout 與最終驗證 |
| BR-01 有限救援修復與正常安裝回歸 | 已結案，詳細結果只看 TEST_REPORT |
| 控制中心入口點擊 | 依使用者指示跳過，不作阻塞、不安排續測；原觀察不轉算通過 |
| 返回導覽 | 原始觀察及工具／網站限制保留，不安排續測 |
| 自然起因、安裝版故障救援與歷史矩陣 | 本輪不執行，不以正常回歸或文件檢查補算通過 |

## 執行邊界

- 文件整理、工具校準或發布不恢復已停止工作；BR-01 原歷史矩陣維持停止。
- P01 bounded prepare／P02 真 gate 仍須使用者明確恢復要求及指定影片自然 pending gate 新前提；不改網站 timeout、重設預算或反覆刷新製造條件。
- 舊失敗、無效窗口及批准等待更正保留；原始輪次見 [HISTORY](HISTORY.md)，完整限制見 [結案紀錄](TODO_CLOSURE_2026-10-13.md)。
- v2.1.6 的已批准結案維持；新增 CDN 研究已撤銷。沒有本輪授權的偏好記憶、提高探測頻率及其他平台擴展不實作。
- 唯一瀏覽器環境仍為 [IAB＋Tampermonkey](IAB_TESTING.md)；此維護任務不啟動任何瀏覽器驗收。

## 維護與追溯

工作狀態只在本頁維護，測試與限制只在 [TEST_REPORT](TEST_REPORT.md) 及原始證據維護；其他入口連至這兩處。新規則見 [文件維護流程](DEVELOPMENT.md#documentation-maintenance)。

歷史交付、停止時矩陣、P05 及各版結案原文保留於 [重整前快照](../archive/retired/docs/DOCS_BEFORE_REORGANIZATION_2026-10-17.md#docs-todo-md)，版本、議題及日期入口見 [HISTORY](HISTORY.md)。
