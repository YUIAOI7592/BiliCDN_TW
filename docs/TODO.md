# 目前工作

現行版本 **v2.2.18**。本頁只維護工作狀態、未完成項目及停止邊界；驗收結果見 [TEST_REPORT](TEST_REPORT.md)，歷史證據由 [HISTORY](HISTORY.md) 追溯。

## 目前狀態

v2.2.18 三批簡化、自動驗證、安全差異及正式發布已完成；公開下載核對通過。前輪更新未完成的 INVALID 保留；使用者確認更新後的 R1 安裝身分與設定內容驗收已完成，入口點擊限制另記於 TEST_REPORT。不自動補跑其他窗口。

本頁沒有新增已確認且待修復的功能缺陷。下列研究、程式整理及證據不足各自列管，不能把缺少實機分支證據改稱功能失效。既有離線效用 FAIL 仍保留。

## v2.2.18 發布後有界驗收

使用者於 2026-11-12 確認已更新並授權續行 L0／S1／Z0；T0 為 00:00:21，原定 00:12:21 起只清理、00:15:21 硬截止，實際 00:04:19 已完成清理並結案。不再下載或更新，不重跑舊窗口。前輪已結束，實際結果只見 [TEST_REPORT](TEST_REPORT.md#來源隔離與實際安裝)。以下保留當輪凍結範圍，不構成再次啟動授權：首次能力檢查前讀時鐘作 T0；總上限十五分鐘，最後三分鐘只清理。最多一個自有 IAB 分頁與一次公開 latest 更新嘗試。L0 核對 Tampermonkey、完整腳本本體、版本、singleton 與 hooks；S1 核對退役三個控制項消失、其餘設定保留，不寫入偏好；Z0 關閉自有分頁並清理工具資源。必要能力不足則記錄未驗證並停止相依項目，不重跑舊播放窗口，不追加正常播放／故障注入。若頁面起播，立即對真正媒體靜音並讀回，無法維持便停止。

## 執行邊界

- v2.2.8 發行採離線交付，後續另獲授權的 R2 專項與原生校準亦已結案；v2.2.6、先前撤除及各版舊輪次維持原結案，自動結果與安裝實測分開。
- 瀏覽器只用 IAB＋Tampermonkey，同時一個自有測試分頁，保持靜音；其餘永久界線與已確認靜音方法見 [AGENTS](../AGENTS.md#使用者永久執行禁令)。
- 已通過項目不重測。新案例必須先凍結範圍、次數、硬截止、清理時間與可沿用證據；不繼承舊輪次剩餘預算或自動安排重跑。
- 原十二個五分鐘窗口、IR36、自然起因、BR-01 歷史矩陣及已撤銷 CDN 研究維持停止／結案，不隨工具恢復、文件整理或發布啟動。
- P01 bounded prepare／P02 真 gate 仍須使用者明確恢復要求及指定影片自然 pending gate 的新前提；不改網站 timeout、重設預算或反覆刷新製造條件。
- 過往輪次對控制中心入口／返回導覽的跳過決定保留；v2.2.6 R1 另獲授權的入口、三頁及重開結果依當輪紀錄，不將舊跳過限制套用為本輪未測，也不追加新的導覽測試。
- 不實作未授權的偏好記憶、提高探測頻率或其他平台擴展；舊採用否決與原 FAIL／INVALID 保留。
