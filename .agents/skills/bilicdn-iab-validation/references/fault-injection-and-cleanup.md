# 故障、連續事件與清理

## 注入前：目標與學習隔離

先選實際邊界。網路故障歸因當前 video／audio 新請求，只在記憶體比對精確 URL，不封鎖整個 CDN 或萬用媒體路徑；SDK 案例只包裝所需回應／Promise，保留 receiver、參數、例外與所有權。原生對照使用自有合成頁。

只持有送出前的自有匹配請求，不取消或重送已開始的網站請求。HTTPDNS／禁止路線先裝精確攔截，不拿真外送證明封鎖。gate 案例於 reload 前建立觀察，保留真請求、pending、等待者順序；不能安全命中就停止，不擴大匹配。

所有可能受注入影響的 transport／startup／challenge 工作都須可歸屬並抑制寫入；沿用工作 ID，不只記網站 requestId。完整資料只在記憶體，輸出數量與有界摘要，受控樣本不能進正式學習。

逐路徑證明抑制有效：[suppressEarlyRetryEvidence](../../../../src-v2/application/routing/route-coordinator.ts) 只控制提前重試證據，一般 evidence.commit 位於其判定之前，不能當作全健康學習隔離。方法存在不表示工具已具備能力；證明不了就不開始該故障窗。

注入、持有、續讀及失敗解除先在合法自有情境校準，邊界對應實際方法。SDK 案例不要求無關 Request 攔截，不開本機服務或新增產品取證介面反證舊版。

## 事件與資源所有權

建立事件流前凍結起點、容量、節奏及截止；前置、窗口、晚到事件維持可追溯續讀。拉取游標立即首次排空，API 有 hasMore 時讀至 false；訂閱型核對序號及遺失訊號，不假定 Fetch／Network 共用游標。截斷、丟棄及空隙明列，沒有遺失旗標不證明完整。

跨呼叫收集器保留狀態、資源所有者與回收入口。閉包讀同一詞法綁定的新值，但已複製物件、參數或不同 executionContext 不自動更新；不能只換外層容器就假定回呼全改接。頁內 registry 先登記唯一 key，回收核對文件及 context，不只依過期 objectId。

先保存整批事件與可證明自有的暫停 ID，再作可能失敗的分類；自有範圍不匹配請求立即放行，不接管其他工具暫停的回應。攔截生效須持續服務事件，背景工作具所有者、截止及清理，不在模型長等待期間留下無人處理的請求。

實際匹配及持有才算施加網路故障；latestRequested 或健康播放不證明命中。影片故障命中影片，音訊故障命中音訊，兩者不可互代。

有期限觀察器自動截止，第一次停止保存真終點；觀察終點、工具返回與清理分開。排程落後跳到下一有效時點，不補抓；保存成功才推進持久續讀位置，重讀去重。晚取回不補邊界，媒體樣本不填 Network 缺口。離線方法契約不等於 IAB 校準。

## 操作與收束

設定走產品命令；復原前確認欄位仍等於工具最後寫值，保留使用者／其他分頁的新修改，不整體 reset／clear 或覆蓋舊快照。拖曳先定位可見進度列，按下立即確認 dragging，否則釋放；先確保前提失效時可即時解除按鍵與攔截，不依賴下一次模型往返才能收尾。

尋位／reload 按[播放器契約](../../../../docs/ARCHITECTURE.md#auto-救援與操作所有權)判定，不改 getter、新建控制器、強制 tick 或重設預算。合法有限位置不一律要求 opaque proof；初始化修訂等條件依實作核對。SDK reload 要有實際操作、修訂與功能狀態，普通 recovered 不能代算。

每項自有資源建立即登記 finally／失敗清理；失聯、截斷或例外先停故障、收束自有請求。保存完整描述子，只復原仍由工具持有的包裝；原為繼承方法就移除自有遮蔽，不覆蓋其他腳本新包裝。

停止新增持有，解除自有攔截模式並處理持有請求，確認後續新請求不再受控。所有可能提交樣本的非同步尾端收束後才解除抑制；零筆數不能證明晚到寫入安全。期限內不能收束時抑制保留至自有文件卸載，其餘資源先清理並列 INVALID；必要時先卸載自有測試分頁再撤攔截，不事後清空學習掩蓋污染。

最後核對請求、攔截模式、包裝、斷點、訂閱、計時器、設定與受控樣本。未完成清理則本輪交付不通過，明列殘留與影響，不留給下一輪；獨立成立的原始觀察仍保留。清理不在播放中解除靜音，解除故障也不等於全部尾端已結束。
