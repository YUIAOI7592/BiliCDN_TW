# IAB 斷言、身分與證據

## 證據層級

| 層級 | 可以證明 | 不可代替 |
| --- | --- | --- |
| N 正式契約 | Node 套件的精確邊界、所有權及交錯 | 原生瀏覽器及實際播放 |
| S 來源隔離 | IAB 自有 HTML／iframe 中真正完成的來源及原生對照 | Tampermonkey 安裝實例或未完成的原生網路 |
| I 實際安裝 | 指定影片中取得的本體、實例／hooks、操作及恢復，各自判定 | 其他站點／格式／瀏覽器或未發生條件 |
| E 環境校準 | 同一 IAB 的控制頁、官方測試或指定影片中本案所需能力 | 產品功能通過 |

S 控制頁直接開本機檔案，僅使用合成資料、注入儲存及自有情境的 FakeClock；不接正式 GM、登入或簽名媒體資料。檔案來源做不到的網路契約列限制，不另架服務。N 不代算 S／I，同一瀏覽器也不讓 S 成為 I；歷史 Chrome 紀錄保留原身分。

S 的行為驗證使用同一自有來源的正常／失敗對照，分別保存原生結果與清理；Node 模型的成功不能代算原生對照。

## 門檻的適用範圍

先定義要證明的結論，再取證。已批准案例不可因取證困難改列選測；更正分類保留原判與更正依據，不補算 PASS。

| 斷言 | 必要證據 |
| --- | --- |
| 一般播放 | 真實進度、暫停／尋位／倍速、錯誤與 UI；不要求完整 Network 或私有快照 |
| 管理器識別或保存內容 | 直接查證管理器；其版本不能替代實際本體，也不是一般播放前置 |
| 載入完整指定產物 | 當前完整載入來源與正式附件比對，辨別包裝；UI 版本、資產清單或保存副本不夠 |
| 唯一實例、引用及 hooks | 相應物件、引用及執行證據；自檢明示來源，不無限追加第三方 hook 鏈認證 |
| 設定操作與保存 | 可信輸入、實際狀態、受影響原值；跨重載另需新文件讀回，同頁往返不代算 |
| 請求歸因、分母、順序、期限 | 相應連續事件、時間基準及精度；缺口只限制相依結論 |
| 前背景或可見性 | 經校準的本案狀態；完整轉換斷言才要求 E04 |
| 受控故障及恢復 | 精確目標、真實注入、學習隔離、晚到工作及清理 |
| 動態協定 | 真正提案／認領／提交順序及結果；方法引用只證明接線 |
| 容量、淘汰、重入、取消或排序 | 先指定 N／S／I；不把每個 N 契約自動轉成 I 壓力案例 |
| 播放窗口或效益 | 凍結樣片、倍率、時長及比較設計；身分查證不承接全片單或歷史研究 |

只取本案需要或會變更的設定、控制及額度，不要求全部私有狀態。新版本／文件／實例只更新受影響證據；播放器更換須更新靜音、狀態及所有權，不撤銷獨立產物校驗。

## 讀值與 UI

入口依實際畫面：播放器設定區或 Tampermonkey 註冊的「⚙️ 開啟 BiliCDN 控制中心」。網站曾使用的設定子選單路徑不是產品契約。封閉 Shadow DOM 可能不出現在 DOM／AX；可用截圖與可信鍵盤／指標，每步核對焦點和結果，不搶焦點，不以合成事件或私有閉包冒充 UI。

讀值須對應真正播放器；DOM 進度／音量與畫面衝突時不宣稱原生狀態，可沿已確認方法讀回播放器音量 0 與靜音圖示。暫停由畫面、進度及產品狀態交叉核對。沒有 console／註冊工具不代表未載入，資產清單也不等於完整本體；hook 自檢不替代外部 Network、唯一實例或完整協定。

允許工具可取得真正 HTMLMediaElement 時，沿[已確認原生靜音方法](../../../../archive/retired/docs/TEST_REPORT_HISTORY.md#2026-10-31依使用者更正靜音方法續行與下載工具超時)設定 `muted = true` 後讀回；必要時以自有 MutationObserver／volumechange 維持，監聽器與觀察者登記清理。其他播放器沿已確認的實際控制方法操作，不修改 getter 冒充讀值。靜音時點、初始區間、音訊下載及清理限制以 AGENTS 為準。

## 原生 API 校準

已授權的原生 API 調查可在同一 IAB 分頁執行既有 [WPT HTTPS 案例](https://wpt.live/xhr/)，先讀測試、參數及資源，保存來源、日期與 harness 結果，不改斷言或計時。它屬 E，不載入產品或正式 GM，不替代 S／I。

本機檔案被 URL 政策拒絕時不以 CDP、代理或其他瀏覽器繞過；官方測試是獨立來源，不是重託管本機案例。超時、無結果及逾期結果分列；逾期畫面不補算有期限窗口。[官方 Browser 說明](https://learn.chatgpt.com/docs/browser?surface=app)不保證當次工具或本專案案例通過。

## 安裝更新與已更新查證

需要更新才用 IAB 既有[公開 latest 入口](https://github.com/YUIAOI7592/BiliCDN_TW/releases/latest/download/BiliCDN_TW.user.js)，以允許工具完成管理器步驟，再於新文件核對執行身分。使用者已回報更新完成或只要求查證時，直接核對，不先下載／重裝。

中繼頁、管理器確認與保存副本不代替實際載入。必要步驟當次受阻且無已授權替代方式時，才說明限制及必要人工操作；不切外部瀏覽器、不改權限檔、不繞過閘門。

## 證據記錄

實際開跑才建立 .work/iab-testing/<日期>-<版本>-<短提交>-<輪次>/。簡單查證可只用一份報告；複雜窗口按需保存 baseline／cases、timeline、cleanup、checkpoint／rerun、report 及 screenshots，不為填模板追加操作，也沒有一鍵 IAB 命令。

逐案記 ID、層級、版本、前提、預期／實際、有效性、結果／原因、起訖、證據及清理。完整本體、倍率、時序、合資格 tick、備援／reload／終止次數僅依斷言需要記錄；未知或不適用明列。重連先讀 checkpoint 再查連續性，相同本體不能填補觀察空隙。

輸出前去除簽名 URL／路徑／查詢／權杖、Cookie、IP、播放器或核心物件；截圖亦核對範圍，只保留必要類別、有界摘要及脫敏結果。歷史 VALID＋PASS／FAIL、INVALID＋null 及原判保持，不回寫遷移。產品閾值讀 [ARCHITECTURE](../../../../docs/ARCHITECTURE.md)，資料邊界讀 [SECURITY](../../../../SECURITY.md)，結果寫 TEST_REPORT 或對應原始紀錄。
