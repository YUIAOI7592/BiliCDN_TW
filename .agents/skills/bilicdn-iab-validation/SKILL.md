# BiliCDN 內建瀏覽器驗收

儲存庫根目錄位於本檔目錄向上三層。先讀當次要求、[TODO](../../../docs/TODO.md) 與 [AGENTS 永久限制](../../../AGENTS.md#使用者永久執行禁令)，只執行當次已授權範圍。方法、工具恢復及發布都不恢復已停止工作。

## 開始前

只用 Codex 內建瀏覽器 IAB＋Tampermonkey，同時一個自有測試分頁；換片、更新及來源隔離共用該分頁，或關閉後再建立。需第二分頁的案例列未執行，不改外部 Chrome／Edge、獨立 Playwright／Puppeteer 或 headless。Tampermonkey 探索禁令已撤銷，CDP 亦有既有授權；依當次工具文件及能力使用，不繞過閘門或重複索取已有授權。

1. 先讀[斷言與證據](references/assertions-and-evidence.md)，列本案目標、N／S／I／E 層級、必要前提、既有可沿用證據及清理；一般查證不自動升格成完整矩陣。
2. 記錄 HEAD、差異、產品版本與可取得的工具版本；從當次文件及回應識別 IAB 和分頁，不硬編舊 ID、不假設特定欄位，不另啟控制程序。
3. 同一有效環境只做一次必要能力確認。工具重連先核對文件／實例連續性，不沿用失效 handle，也不無條件重做全套；前輪自有請求、包裝、計時器及斷點須已清理。
4. 播放或背景斷言才讀[播放與可見性](references/playback-and-visibility.md)；故障或連續請求時序才讀[故障與清理](references/fault-injection-and-cleanup.md)，必要前提不足不開始相關案例。

全程遵守 [AGENTS 永久限制](../../../AGENTS.md#使用者永久執行禁令)。導覽／起播後立即靜音並讀回、換媒體重新核對，操作及已確認方法見[讀值與 UI](references/assertions-and-evidence.md#讀值與-ui)；不追加起播前門檻，不能維持靜音便停止相依播放案例。

## 有界執行

開跑前凍結案例 ID、版本／差異、層級、前提、事件順序、預期返回／狀態／副作用、精度、窗口、總時限、階段上限及清理時段。第一次最小工具檢查為 T0，保存 Asia/Taipei 時間及單調計時；工具往返、等待、更新及歸因都計入截止。剩餘時間不夠完整窗口就列未執行，不縮短窗口或侵占清理。

故障恢復依斷言選擇自然或受控情境；自然起因不是全部救援修復的通用前置，已指定自然情境的案例仍保留其必要條件。

同版本／倍率／前提先做一個完整窗口；通過且仍適用不重跑。無效窗口須當次重跑授權及新前提，不繼承舊輪次次數或預算。必要非同步結果完成才採用；拒絕、超時、原因未知與歷史成功分開。內部 timeout 不保證外層工具／權限等待有界，這也不表示全部能力不可用。

長等待、下載及取檔需可觀察的外層截止；權限等待或斷線破壞必要連續性時作廢相依窗口並清理，不拼接前後證據。能區分的執行與等待時間分列，否則記未量測。前提失效只限制相依結論，繼續可獨立完成的合法工作。

## 判定與交付

| 結果 | 適用條件 |
| --- | --- |
| PASS | 有效觀察及必要證據支持全部斷言，附預期／實際／證據 |
| FAIL | 有效窗口觀察到斷言不符；產品歸因另外判斷 |
| INVALID | 已開始，但必要前提或證據完整性失效 |
| 證據不足 | 完成觀察，必要自然條件或樣本未出現 |
| 未執行 | 因範圍、工具、安全前提或時間限制未開始 |

核心全部 PASS 且清理通過才宣稱核心完成；必要項目其餘結果明示未完成範圍，不刪行、降級或用「待驗收」遮蔽。管理器與未啟動研究的無關缺口不需豁免，Network 缺口不否定獨立成立的播放、UI 或本體證據。

確認缺陷先收束、保存最小案例／正常對照、來源與根因，再停止擴大窗口；已授權修復依[變更驗證](../bilicdn-verify-change/SKILL.md)及[發行流程](../bilicdn-release/SKILL.md)交付，不附加新矩陣。只剩工具／自然前提問題時交付終局結果與再開條件，不循環重試或排程下一輪。

結果依[證據記錄](references/assertions-and-evidence.md#證據記錄)保存，工作狀態只改 TODO；原 FAIL／INVALID、歷史格式與發布快照不回寫。一次未再現不證明舊根因已解決，合法備援或音訊成功不代算指定影片供片成功。
