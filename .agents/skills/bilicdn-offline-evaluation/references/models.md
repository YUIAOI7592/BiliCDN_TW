# 離線模型、來源與限制

## 原版與 v2 獨立比較

[upstream-compare](../../../../scripts/evaluation/upstream-compare.mts) 固定讀取並驗證既有 v1.3.4 原件與已發布 v2.1.27 完整腳本；每版／情境在新 Node 子程序及模擬頁面執行。先校準，再完整摘要或 JSON；未知／重複選項退出 2，失敗或無效退出 1，全部有效且適用斷言通過退出 0。

v2.1.27 從公開封存清單與 ArchiveStorage 讀取，須符合固定大小及 SHA-256；不要求還原散件、不從網路補抓，缺少唯一位置、損壞或雜湊不符即失敗。非同步載入仍受既定 CLI 與情境期限約束。

共用 FakeClock、記憶體 GM、固定 AVC、共同合法來源及前景模型，1／2 倍分開，六十秒健康前置後執行固定情境。進度與可信事件都是 Node 模型，不能代算瀏覽器輸入或實際播放。原版缺少核心 reload／還原能力的專屬斷言列不適用，共同斷言仍執行。

單案例與清理各五秒，子程序外層六十秒，輸出上限 32 MiB。頁面計時器／監聽與未完請求分開盤點，由模擬頁面釋放；強殺程序或強清時鐘不算通過，也不取代產品 dispose。verify 只執行不載入原件的中立工具契約，不執行兩版比較。

## 提前重試效用

evaluate:early-retry 的六個固定情境保存 policy／input SHA-256、預測、held-out 未來供片、停頓及不必要重下載。退出 0 表示效用門檻全過，1 為效用 FAIL，2 為非法參數。工具不連網、不新增執行期依賴，不能把失敗改為預期結果或外推原生瀏覽器收益。

## 選路模型對照

| 模式 | 固定基準與主要輸出 | 限制 |
| --- | --- | --- |
| 預設十場景 | v2.2.6 的 048b0f94e6bb98922ee5bcc0d1b30003cf3b12a9 與當前純政策；首段時間、緩衝不足、換站、下載、探測數／量、重載及輸入雜湊 | 需要本機完整 Git；三秒等待與探測按相同最壞上限，未模擬恢復而 reload 固定零，不證明實機沒有重載 |
| optimization | 當前純政策的 7,680 組條件、五種相同決策前提的未來、1／2 倍均勻與 VBR 軌跡，輸入／政策／工具雜湊 | 先決策再揭露未來；比例不作現場適用率，不讀私有資料、舊報告、bundle 或 GM |
| deadlines | 304c631 舊純政策與當前純政策，同數字／服務軌跡及資源上限；預測、平均誤差、低估、期限誤判、等待、換站及下載 | Auto 為明列的外生假設，未重建網站私有 ABR；探測部分下載為線性假設，reload 未模擬固定零 |
| measurement | 當前純函式與已審閱合成數字；零起點、清理延遲、牆鐘跳變、VBR、倍率、快照年齡及獨立公式 | 輸出保留 304c631 基準標記，但不載入舊版模組或要求 Git；零誤差只證明算式一致，探測／恢復／Auto 效果維持未知 |

選路模式退出 0 只表示模型完成，非實機效用通過。[現行入口](../../../../scripts/evaluation/routing-evaluation.mts)僅在包含 optimization 時嚴格拒絕多餘選項；其他分支依 deadlines、measurement、預設的順序選擇，未知選項可能落入預設。因此使用入口列出的精確命令，核對輸出模式，不把退出 0 當參數合法證明。

原十場景與提前重試六情境彼此獨立，原 FAIL 保持。未選主機或沒有替代服務不因缺值算失敗；held-out 未來與估計分離，保留估計勝出卻實際較差的反例。

optimization 前三種未來為持續慢、原路恢復、替代變慢，另有替代未知與交接未確認。片段序列下載、整段完成才 append：耗時＝回應等待＋bytes × 8／本文 bits/s，期限＝連續媒體緩衝／實際倍率，停頓＝超期部分，完成緩衝＝max(0, 舊緩衝−倍率×下載秒數)＋片段媒體秒數。FPS 不再次乘碼率；不模擬漸進 append、網站 ABR、解碼或音訊競爭。

兩秒交接預算只算一次，合成實際交接另列；輸出完成時間／停頓差、期限誤判、額外下載及換站。未完成／未知、未模擬探測／reload 為 null，不能解成零成本。算式、守恆及重現契約見 [v2212-evaluation](../../../../tests-v2/cases/tooling/v2212-evaluation.ts)，模型組數不計正式案例數。

deadlines 保留競爭流量、速度突降／回升、VBR 大段、過期緩衝及交接預算抑制重試的反例；數字對照不是未來分位數保證。measurement 不讀私有研究、封存原件或網站 bundle。

## 資格與取證邊界

請求資格／實傳案例見 [up141-retry-transport](../../../../tests-v2/cases/transport/up141-retry-transport.ts)，控制器與政策見 [up141-retry-policy](../../../../tests-v2/cases/routing/up141-retry-policy.ts)。正數 timeout 的提前重試排除與正數 timeout 起播等待是不同契約；progress 須可信、200 不冒充 206，主動探測不取得替代權限。產品閾值、一次許可、選路與備援資格由 [ARCHITECTURE](../../../../docs/ARCHITECTURE.md)維護，模型不能繞過前層條件。

私有離線取證方法只核對排程落後跳到下一有效時點、保存成功再推進游標、部分失敗重讀去重、來源截止不延長、容量溢位及尾段缺口；它不是正式採樣管線或 IAB 能力證據。實機分母、自然觀察與成本限制由 [HISTORY](../../../../docs/HISTORY.md#提前重試現場適用率與成本)追溯，不新增產品取證介面。
