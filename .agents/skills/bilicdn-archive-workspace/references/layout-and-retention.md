# 目錄、分類與工作資料

## 儲存庫配置

| 位置 | 現行用途與維護界線 |
| --- | --- |
| src-v2／tests-v2 | 正式來源及具名契約；模組歸屬依 [ARCHITECTURE](../../../../docs/ARCHITECTURE.md) |
| scripts | 正式建置、封裝、測試、verify 與啟動器；checks、testing、evaluation、lib 各有現行消費者 |
| .agents/skills | 專案流程的 Skill 及按需參考，Git 追蹤；其他 .agents 內容繼續本機忽略 |
| docs | 現行產品規格、導航、工作狀態、驗收結果、授權及文件清單 |
| `Release/v<version>` | 僅現行版本五項原始封裝檔，發布後不回寫 |
| dist | 本機正式腳本、map、build-manifest，Git 忽略；verify 暫存由工具收束 |
| baseline | 不可變上游原件及校驗，維持來源歸屬，不作正式 v2 建置／測試輸入 |
| node_modules | 現行精確開發依賴，Git 忽略，不當成舊檔搬走 |
| tools | 有明確現行用途的本機獨立工具，按需建立、Git 忽略；登記用途、輸入、依賴及離線方法 |
| .work | 已批准且實際開始的活動任務資料、待釐清原件；Git 忽略 |
| .git／.codex | Git 管理及本機代理資料；不以整理理由清 Git 物件或建立重複工具鏈 |
| archive/retired/docs | 可讀的歷史報告、研究及追加日誌 |
| archive/retired/bundles | Git 追蹤的公開 TAR＋gzip 原件包 |
| archive/retired/local | 被忽略的私有原件、包及清單；名稱與內容不公開 |

版本由 [release.json](../../../../release.json)決定，實際搬移與保存位置由[公開清單](../../../../archive/relocation-manifest.json)登記，結果見日誌；不在本頁重列會變動的檔案數。歷史邏輯路徑可以只存在包內，不要求散件永久在原位置。

根目錄維持 README、AGENTS、SECURITY、LICENSE，以及 package／lock／release、三個 tsconfig、格式與 Git 設定的慣用位置。tsconfig 分別對應產品 DOM、測試 Node＋DOM、工具 NodeNext；正式格式範圍由工具清單決定，編輯器排除不能代替它。新增設定先查既有權責，不為檔案數搬動慣例位置。

## 分類與保存

現行公開來源、測試、工具、Skills 與設定隨變更維護。歷史報告及日誌保留證據用途，大型原件依任務分包；閱讀版只允許可重建且登記的 URL 編輯。私有唯一證據、必要工具及 metadata 保存；經核對可重建的依賴、Git 容器及驗證副本才可清除。未知資料保留，不將封存作產品輸入或整包覆蓋現行來源。

正式入口以實際消費者、CLI、套件登記、子程序及動態歷史輸入判定；沒有外部匯入不代表無用途，getter、序列化及副作用也須檢查。只移除證實無作用的支架，不以減少行數為目標。已撤除診斷與 IAB 專用執行器不恢復；一次性工具隨相應證據保存，不因可執行就升格為正式工具。

## 工作資料與結案

只有任務真正開始才建立 .work 等暫存位置。結案按任務與日期保存必要原件及操作紀錄，相同內容一份，私有索引記原位置至保存目標。Codex Runtime 每次由依賴工具取得，不複製進專案，也不為歷史 up141 Runtime 建立保留需求。

先釋放自有資源，完成來源、雜湊、壓縮與獨立還原證明後才移除原位置及可重建副本。舊報告位置描述當時狀態，現行查找依清單；不能只改文件聲稱清理完成，也不能因暫存原件尚在就宣稱案例資源未釋放。

核對原始位置、存取失敗、首次可讀雜湊與逐位元組比較時分列實際證據。dist 僅保留三項正式輸出，過往 Release 完成封存後移出現行目錄；還原／staging 副本驗證後同批清理。未知用途或仍可能活動的項目不依日期自動刪除。
