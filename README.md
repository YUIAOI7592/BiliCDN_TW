# BiliCDN_TW

BiliCDN_TW 是針對台灣網路環境維護的 Bilibili Tampermonkey 腳本，提供 CDN 選路、自動測速與有限度的故障恢復。

正常模式預設從腳本的 **內建節點清單（Catalog）** 與 B 站當次提供的合法原始／備用網址選路。「允許參考 B 站原生來源」預設啟用；關閉後只使用 Catalog。

版本以 [release.json](release.json) 為準。可直接前往[安裝與更新](#安裝與更新)、[控制中心](#開啟控制中心)或[問題排查](#卡頓或黑屏時如何排查)。

> [!IMPORTANT]
> **原作者與原始腳本：** [jiyunshi－Bilibili CDN 台灣優化](https://greasyfork.org/zh-TW/scripts/579776-bilibili-cdn-%E5%8F%B0%E7%81%A3%E5%84%AA%E5%8C%96)。本儲存庫源自原作者 MIT 授權腳本的個人修改專案；v2 是以 TypeScript 重新設計與重構的版本，並非原作者的官方版本。
>
> **AI 協作聲明：** 本修改版的維護者本人不具備自行撰寫程式的能力；程式分析、修改、測試與文件主要由 AI 協助完成。使用者應自行判斷是否適合安裝。

## 安裝與更新

1. 準備 Tampermonkey，依管理器提供的介面安裝使用者腳本。
2. 開啟 **[安裝／更新腳本](https://github.com/YUIAOI7592/BiliCDN_TW/releases/latest/download/BiliCDN_TW.user.js)**，並在 Tampermonkey 確認安裝。也可從 [最新 Release](https://github.com/YUIAOI7592/BiliCDN_TW/releases/latest) 取得同一檔案。
3. 核對管理器內腳本版本。
4. 重新載入 Bilibili 影片分頁，讓新版本生效。

腳本的自動更新網址固定指向本儲存庫的最新 Release。從 v2 更新會沿用既有 v2 設定與學習資料；v1 設定不會遷移，使用 v1 的使用者請停用舊腳本後安裝 v2。

手動更新使用同一連結及步驟。GitHub Release 只提供 `BiliCDN_TW.user.js`；建置資訊與校驗碼保存在儲存庫的 [Release 目錄](Release)。實際測試環境與驗證範圍見[驗證紀錄](#目前版本的驗證紀錄)。

## 功能概覽

- **自動或固定 CDN：** 依合法候選與近期傳輸證據選路，也可指定內建節點。
- **影片與音訊分開判斷：** 量測、健康證據與故障處理分開記錄，避免互相影響。
- **有限度的測速與恢復：** 起播最多三個候選，有已知足速來源時保留一個探索名額；健康播放期間更新證據，遇到符合條件的故障時才嘗試備援或重建播放器核心。
- **保留播放選擇：** 倍速由使用者／B 站播放器決定，包含 2x；腳本依目前倍速估算需求。畫質與影片格式都由 B 站決定；腳本保留原始表示順序。
- **背景播放協助：** 減少頁面切到背景時因可見性事件造成的播放中斷；健康測速仍會檢查分頁是否真的在前景。
- **連線與節點控制：** 可阻止網頁使用 WebRTC、HTTPDNS，並設定個別 CDN 的可用性。

### 播放資料格式

支援 DASH 及 MP4／FLV 分段播放資料，保留原有分段順序、時長與大小。番劇正片的 OGV `playview` 沿用相同處理，片頭 `pre/check/drm` 原樣通行；不變更網站的畫質與格式選擇。格式接納、整份輸出檢查及來源授權詳見[架構指南](docs/ARCHITECTURE.md#內容格式與授權)。

## 開啟控制中心

可從以下任一入口開啟：

- Tampermonkey 選單中的「⚙️ 開啟 BiliCDN 控制中心」。
- B 站播放器設定面板中的「⚙️ 開啟 BiliCDN 控制中心」。

| 頁面 | 可以查看或操作的內容 |
| --- | --- |
| 總覽 | 緩衝、安全吞吐、需求餘裕、影音回應、最近播放資料及測速／恢復／提前重試狀態；可展開詳細狀態 |
| CDN | 自動／固定模式、原生來源開關、個別節點可用性及熔斷現況 |
| 播放設定 | 六個功能開關、整體停用，以及摺疊的清除／重設工具 |

控制中心內聚焦按鈕後可用 Enter／空白鍵操作，Escape 關閉；表單與 Tab／Shift+Tab 保留瀏覽器原生行為。

### 如何閱讀總覽

緩衝、速度、需求與影音節點各依自己的有效資料顯示。有播放器尺寸但尚未辨識影片時，會標示編碼未確認；有速度但缺需求時仍顯示速度。缺值旁說明等待資料或樣本不足，不等於播放故障。

安全吞吐來自目前路線主機的有效影片樣本，並區分近期容量、單筆試用、歷史估計與待再驗證。需求餘裕依已確認碼率及實際倍率計算；影音回應欄只列實際觀察到的回應，送出目標不冒充回應主機。最近播放資料僅保留一筆接納摘要。完整計算、時效與缺值規則見[顯示契約](docs/ARCHITECTURE.md#控制中心資料流)。

### 自動功能與香港節點

以下六項位於「播放設定」，預設值與升級保留方式統一見[預設設定](#預設設定)。

| 功能 | 開啟／關閉效果 |
| --- | --- |
| 起播提前放行 | 所有合法模式的首個足速候選可提早釋放；關閉仍等待全部候選或原三秒期限 |
| 健康中段探測 | 大小可靠時探測中段；關閉使用首段，大小與範圍驗證保持 |
| 備援家族分散 | 合格備援優先分散家族；關閉恢復原排序 |
| 慢請求提前重試 | 完整資格成立才要求原生 timeout，交由網站自行重試；關閉抑制新動作、撤銷待認領許可 |
| 阻止網頁使用 WebRTC | 沿用封鎖能力；關閉依所有權還原描述子 |
| 阻止網頁使用 HTTPDNS | 攔截已辨識請求；關閉後續請求走正常傳輸流程 |

「慢請求提前重試」啟用後仍須符合完整資格；現行正數 XHR timeout 不適用這項功能，但可參與起播測速。獨立效用評估仍為 FAIL，啟用不代表已證明能改善播放；證據與限制見[完整驗證報告](docs/TEST_REPORT.md#驗收結論)。

香港清單為 cn-hk-eq-01-03.bilivideo.com、cn-hk-eq-01-05.bilivideo.com、cn-hk-eq-01-01.bilivideo.com，作為一般 Catalog 節點預設可用；既有逐台覆寫保留。它們沒有特殊選路優先權，仍遵守來源授權、禁止、健康證據與親和規則。勾選只表示允許使用，實際回應主機見總覽。

### 三種使用模式

| 模式 | 可選來源 | 測速與自動恢復 |
| --- | --- | --- |
| 正常模式，原生來源關閉 | 安全產生的合法內建 CDN 主備網址 | 依播放狀態與限制執行 |
| 正常模式，原生來源開啟（預設） | 內建 CDN，以及 B 站當次提供的合法原始／備用網址 | 依播放狀態與限制執行 |
| 停用腳本 | 網站原本的請求 | 停止腳本改寫、主動測速與恢復 |

關閉原生來源時，已辨識影音若無法安全改寫、沒有合法 Catalog 路線，或請求方式不適合改寫，會在送出前擋下並顯示原因。Catalog 與原始來源若恰好同主機，產生的網址可能相同，仍屬合法 Catalog 路線。

### 預設設定

| 設定 | 預設值 |
| --- | --- |
| 腳本 | 啟用 |
| 選路 | 自動挑選合法內建 CDN 與當前原生來源 |
| 允許參考 B 站原生來源 | 開啟 |
| 起播提前放行／健康中段探測／備援家族分散／慢請求提前重試 | 開啟 |
| 阻止網頁使用 WebRTC | 開啟 |
| 阻止網頁使用 HTTPDNS | 開啟 |

以上布林預設適用新安裝、缺值、非法欄位及還原預設；升級保留既有明確 true／false，讀取不強制寫回。設定保存於本機，跨分頁同步依管理器及平台能力；逐台節點覆寫同樣保留。

Catalog 為 **14 個節點，其中四個預設不可用**。勾選或固定 CDN 不解除禁止與熔斷；完整清單見 [catalog.ts](src-v2/domain/catalog.ts)。

### 測速、封鎖與清除資料

測速由腳本依資格自動安排。以下清理與重設位於「播放設定」的摺疊維護工具，須於控制中心內確認。

| 控制中心操作 | 實際作用 |
| --- | --- |
| 清除測速紀錄、黑名單與故障標記 | 清除健康證據、節點限制與測速協調資料，保留功能設定 |
| 還原預設設定（不清除測速紀錄） | 重設功能與節點設定，保留既有測速紀錄 |

## 選路、測速與恢復規則

腳本在合資格起播時共用最多三秒的路線預測試，網站有設定 XHR timeout 也可參與；原 timeout 保持，測速等待另計，因此總等待時間可能增加最多三秒，實際放行仍受瀏覽器排程影響。網站自行取消仍會生效。健康播放時才安排一般探索，探索結果不會直接更換正在流暢播放的 CDN。

起播早放、中段探測與家族分散的開關效果見[功能表](#自動功能與香港節點)。來源資格、探測預算及細則統一見[產品契約](docs/ARCHITECTURE.md#量測與恢復)；主機家族標記不代表已證明物理機房獨立。

停滯時可按一般／長 seek 政策切換合法備援並有限重載；有效可信目標與倍速可依所有權還原，真正位置 0 有效。新操作與資格失效會撤銷舊動作，不永久沿用最後非零位置。具體時點、額度、例外與取消條件統一見 [產品契約](docs/ARCHITECTURE.md#auto-救援與操作所有權)。

固定 CDN 是合法候選間的優先偏好；該台失敗或受限後，仍可使用其他合法備援並按原規則恢復，不會改寫你的固定設定。固定或勾選節點不解除禁止或熔斷。

CDN 頁與總覽詳細狀態會區分共享的熔斷等級、隔離截止及本分頁的穩定觀察。單筆成功或速度紀錄過期不會清除故障等級；沒有足夠實際傳輸時維持等待，不額外測速。完整規則與新舊版並存限制見[熔斷與觀察](docs/ARCHITECTURE.md#熔斷與降級觀察)。

CDN 是否可用取決於當時的網路、媒體與網站回應；指定節點、測速或自動恢復都不能保證每次播放成功。

## 卡頓或黑屏時如何排查

1. 查看總覽的緩衝、影音回應與恢復狀態，記錄當時倍速及操作。
2. 確認 Native 開關、固定 CDN 與禁止設定是否符合預期。
3. 到 [GitHub Issues](https://github.com/YUIAOI7592/BiliCDN_TW/issues) 提供腳本、瀏覽器／管理器版本及可重現步驟。

一般播放問題不要求診斷報告或完整 Network 匯出。若特定問題需要請求時序，僅取必要資料；不要公開簽名影音網址、權杖、Cookie 或原始網路匯出檔。

## 本機資料與隱私

設定與學習資料保存在 Tampermonkey 本機儲存空間。播放與主動測速仍會對 CDN 發送請求；腳本不提供事故錄製、診斷報告、複製或匯出功能。

本機資料包含功能設定、節點限制、影音健康證據及共用測速冷卻／游標。四個儲存鍵及所有權由[架構指南](docs/ARCHITECTURE.md#狀態層)統一說明。

完整簽名影音網址、路徑、查詢字串、權杖、播放器物件及事故時間線不寫入持久儲存。簽名網址只在目前播放生命週期的記憶體中使用。
