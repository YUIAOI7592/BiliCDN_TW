## 收集器修復與工具契約

host 狀態只保存分頁識別、remote object 識別、游標及資料，不封存 CDP capability。每次完整 await 的步驟明確取得當前 capability，先排空、等待八秒、再排空；不留跨工具呼叫的背景 Promise，也不穿插其他工作。不同分頁在派送前拒絕；過期或失敗的會話不能靜默重啟。

遠端排空傳回並驗證固定截止、經過時間、租約餘額與資源數，保留三十秒租約。binding 與 session 使用同一高精度時鐘起點，避免建構期間的微小差值使合法樣本被當成未來資料。觀察總長為 430000 ms，包含取樣對齊餘裕；計分仍為首筆有效樣本後六十秒開始的 300000 ms，後續仍須完整覆蓋 65000 ms，沒有放寬判定。

新增五個正式具名工具契約：租約／固定截止證據、完整長會話續租、舊分頁在派送前拒絕、延遲續租失效且不能重啟，以及小數毫秒時鐘起點。前後兩個工具缺陷分別保存真實紅色退出 1；修復後轉綠。原有取消、突發、溢位、缺樣、資料投影、門檻及非干預契約仍執行。新增五案與本輪十二個證據重播分開記錄，不回寫發布時的 2595 案。

工具來源完整 verify 已通過 2644 案、tooling 483 案；最終文件、乾淨來源與交付核對依實際完成時間追加於 [工具紀錄](../../../docs/TEST_TOOLING_REPORT.md#2026-10-25實際緩衝效用第二輪完整十二窗)。
