## 工具契約與紅綠證據

新增 evaluate:buffer-live、單一會話／租約／游標、白名單投影、實際進度中斷、十五／六十秒後續及固定採用決策。工具不重算 candidate，不新增產品控制入口。會話限制為 512 筆樣本、4096 筆事件與 4 MiB；重讀返回副本，超量、失效、取消與來源例外停止並清理。

兩個工具缺陷先紅後綠：缺樣後仍將較晚中斷配對為成功預警；既有候選進入一至四秒範圍時漏掉可介入機會。舊工具來源 SHA-256 為 `14f8cd8ae35583b8d1769294c06595cfb02a9572c68431f8458045f65855780a`；紅色執行退出 1，期待／實際保留於 JSON。它們不是產品缺陷。

其他契約覆蓋續讀／重讀、租約與固定終點、超量、例外、取消、未來時間、CDP 例外／跳號、缺樣／換所有者、固定來源拒絕及採用門檻。兩個整合使用真實 Monitor／Runtime／Routes／Recovery／Recorder；有無工具訂閱的事件、儲存寫入、親和及 SDK 副作用相同。先清理工具，再釋放產品測試資源。

既有 readonly 排名不足以驗證全部替代授權及兩筆六十秒內證據，因此 cachedAlternatives 只是舊排名的觀察數量，alternative 保持 null；不讀私有控制器狀態、不用排名推定資格，也不為補資料新增產品 API 或探測。這項缺口不能被正常播放結果補算。
