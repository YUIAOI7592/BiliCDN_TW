### 舊依賴

13 份舊依賴樹共 26,687 檔。以獨立暫存目錄重建三組精確依賴，使用 Codex 內建 Node 24.22.1、npm CLI 11.20.0，停用安裝腳本、稽核及資助查詢，不重新安裝根依賴。26,674 檔與乾淨解析來源逐位元組相符，另 13 個不相符的必要安裝中繼資料原樣封存。

其中 GFM 舊副本缺少原 package.json，從完整隱藏鎖定清單及完整性值建立獨立重建輸入；只主張套件檔案可重建，不主張重建了原專案設定。esbuild 安裝後複製的執行檔以乾淨來源同雜湊檔案核對，未執行舊安裝腳本。

### Git、副本及 TAR

九份獨立 Git 副本均核對 refs、索引、未提交差異及不可達物件。主倉庫基準可達歷史之外的 39 個物件另存無 delta pack，於獨立 Git 目錄還原、核對物件型別／大小及 refs，`fsck` 通過。其餘工作檔與 Git 中繼資料按內容保留或登記重建依據；不宣稱恢復原 pack 的二進位排列。

冗餘清單另含 2,324 個可由固定 Git blob 還原的檔案、327 個已有保留原件的重複檔、1,851 個 Git 物件儲存容器及四份與 `git archive` 重建 TAR 全檔 SHA-256 一致的副本。其他不能逐位元組重建的 TAR 保留原件，包括公開 PRE_CLEANUP TAR，不因內容類似便刪除。

## 索引、還原與引用

公開 [schema 2 清單](../../relocation-manifest.json) 登記壓縮包及成員雜湊，私有索引由公開清單只釘住位元組數及 SHA-256，公開模式不讀私有內容。schema 1 與舊保護基準仍可驗證；新位置不覆寫原雜湊。

檢查器使用共用串流讀取介面，拒絕路徑逃逸、連結、重複／多餘／缺漏成員、宣告大小不符、雜湊錯誤與損壞壓縮。所有新包先由獨立原生 TAR 解壓，再逐檔核對。還原只在新建空暫存目錄；標準解壓及唯讀 `--restore-root` 指令見 [開發指南](../../../docs/DEVELOPMENT.md#壓縮清理與還原)。

19 個現行歷史導覽改指固定 Git 提交，101 個不可變歷史引用增加精確位置證明；其中 95 個指向已核對包內成員，六個舊目錄以其原版本的 Git tree 證明。這不是對失效歷史網址宣稱通過，也不產生空轉接檔。三份日誌另增加基準提交全文前綴保護，既有原保護項目不改寫。
