## 資料字典

| 資料 | 定義與用途 | 缺值及界線 |
| --- | --- | --- |
| 持久時間 | 牆鐘毫秒，TTL／跨頁冷卻 | 不與單調時鐘相減 |
| 工作耗時 | 注入單調毫秒，原生送出至可觀測終止 | 無時鐘、倒退、零耗時不取速度，不夾一毫秒 |
| 回應等待 | Fetch／probe Response 可用或 XHR 回應事件 | ttfbMs 是相容名稱，不是精確 RTT |
| timingBasis | fetch-consumer、xhr-terminal、probe-reader | 舊樣本可讀；不同語意不混入新版完成比較 |
| bytes | 實收與預算計入量分開 | 矛盾／超範圍不取得速度資格 |
| 請求大小 | 閉合 Range 安全整數長度 | 不用事後長度冒充事前已知 |
| 播放事實 | 當前媒體／內容／表示／操作，實際倍率與連續媒體緩衝 | 暫停、倍率、尋位、清空及所有權變更撤銷 |
| 剩餘期限 | 媒體緩衝／倍率，扣單調採樣年齡 | 恰好兩秒有效；只扣一次，不跨等待重用 |
| FPS | 可信表示可選有限正數／分數 | 不取整、不授權、不阻擋；未知保持缺值 |
