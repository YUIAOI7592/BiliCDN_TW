初始遍歷沒有讀取失敗或 reparse point；靜態依賴初篩的十八個未直接 import 項目，逐一確認為套件登記、reporter、worker 或獨立子程序情境。以動態套件路徑、命令參數及 esbuild entryPoints 補核對，不將「搜尋不到直接 import」當成無用途。僅供控制測試的抑制能力有既有契約，保留，重封裝留待獨立優化。

六個格式化副本與 Git blob 原始位元組一致，可由 cat-file 精確重建；Node ZIP 與既有 SHASUMS256 相符，保留現用解壓工具鏈及原始校驗清單。其他沒有精確重建證明的中間工具／副本封存，不刪除。

逐檔清單、消費者、雜湊、保護引用、處置與操作日誌留在本輪私有目錄；額外私有清單以公開登記供 archive:check --local 核對，但內容不進入 Git。全部搬移先複製、校驗，再移除來源；未使用廣域 git clean、網站服務、瀏覽器或活動資源重設。

固定提交的 2,261 案基線及新增八案已通過；完整最終驗證、案例對照、封存與公開交付結果以[最新版完整報告](https://github.com/YUIAOI7592/BiliCDN_TW/blob/main/docs/TEST_REPORT.md)為準。操作腳本先通過 1,578 項零異動安全預檢，保留原程序／路徑限制；後續逐項實際結果與私有封存雜湊均保留。
